# Linux y Terminal

> La terminal no es una interfaz anticuada — es la interfaz más eficiente que existe para controlar un sistema. Todo servidor de producción que alguna vez administres vive aquí.

**Sub-área:** `01-fundamentos/linux-y-terminal` · **Nivel:** Fundamentos → Intermedio · **Lectura activa total:** ~60 min

---

> [!IMPORTANT]
> **Al terminar esta sub-área deberías poder:**
> - Administrar archivos, permisos y usuarios en cualquier sistema Linux/Unix
> - Escribir pipelines de comandos que procesen texto y datos sin salir de la terminal
> - Conectarte a servidores remotos, inspeccionar procesos y diagnosticar problemas de rendimiento
> - Automatizar tareas repetitivas con scripts Bash

## Prerequisitos

- Una terminal con acceso a un sistema Linux, macOS o WSL2 (Windows Subsystem for Linux)
- Python 3.11+ instalado (se usa en algunos ejemplos de scripting)
